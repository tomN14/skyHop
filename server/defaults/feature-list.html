Campaign & worlds

  • World 1 built-in campaign (50 stages); a valid owner upload is used by Play
  • World 2 harder campaign; unlock after clearing all World 1 (account flag + achievement)
  • World nav on menu; collab can scope World 1, World 2, or both
  • Easy / Normal / Hard presets; Custom physics & rules panel
  • Resume progress per world (local); pause → “Do not save my progress”
  • Play / Continue; skip stage when custom rules allow
  • Win screen, run timer, death counter on HUD
  • Submit run for leaderboard review (signed-in); campaign run sessions & checkpoints on server
  • Online coin pickups on campaign stages (persisted per level slot)
  • Achievements; coin rewards when runs are logged to the server

Movement & combat

  • Run, jump, air control; mouse / keyboard / touch controls
  • Camera follow; sensitivity setting
  • Grapple hook stages — hold Shift (or Q) to aim, release to zip toward the hook
  • Gravity arrows and gravity zones
  • Wooden sword & shield pickups; weapon modal; epic boss player HP & heal potions
  • Regular boss (stomp HP); epic boss fights; monster chase stages
  • Projectile / fireball emitters; optional projectile tuning in menu

Stage elements

  • Platforms (including rotated); underhang rules; moving platforms (horizontal & vertical)
  • Spikes, lava, goals, spawn points
  • Teleport portals (green landing dot) and simple switches that move a linked object
  • Collectible coins in stages
  • Stage prep / normalization pipeline for bundled & API stages

User levels & editor

  • My Levels: draft, save, test play, beat-to-upload, publish
  • Online levels list: browse, play, metadata
  • Visual level editor (platforms, hazards, coins, movers, portals, switches)
  • Profanity filter on level titles (client NN + server censor)
  • Staff can edit non-owner user levels from mod dashboard
  • Admin (exactly one): moderator powers, promote mods, 1-day bans (2/week); longer bans and demotions go to the owner
  • Report Advisor: pending reports only — dismiss or escalate to the owner; no dashboard, owner tools, or bans
  • Owner: edit / append built-in World 1 & World 2 stages; Upload ALL saves them to Play
  • Owner: add worlds (unlock checklist) from the button above leaderboards; add that world’s stages from the owner inbox

Racing

  • Race vs bots (offline)
  • Online race: host picks World 1 or World 2 before creating a session
  • In-session chat (lobby + during the run); profanity censored
  • Server anti-cheat on online races (movement, timing, input); offline bot races stay local
  • Live in-race top-5 leaderboard HUD; race over screen
  • Race runs logged separately from campaign on the server

Collab

  • Host / join collab room; shared boss HP bar
  • Everyone wins together; no catch-up teleport
  • World scope: W1, W2, or both stages in one run
  • In-session chat (lobby + during the run)

Economy & cosmetics

  • Owner: gift coins, remove coins, grant texture files

Recordings & submitted runs

  • In-run video recording (account); clips under the size limit stay one file, longer ones split into 15-minute chunks
  • Input logs captured and uploaded (private storage)
  • Record Run and Input Log captures both and saves to My Recordings and My Logs
  • Submit run flow: pick one or more recordings + logs in order, staff review
  • Auto coins: 50 on submit, 50 on accept, plus (11 − rank) × 50 if that run is top 10
  • Mod: Submitted Runs search (approved / declined / unreviewed)
  • Owner: Reviewed Runs queue, lock status, decline reasons

Moderation & owner tools

  • 📧 Reports inbox FAB (Report Advisor / mod / Admin / owner); badge counts
  • ⚠️ Strikes (owner FAB below 📋): permanent until the owner removes them. Player 3 → automatic 1-week ban; moderator / Report Advisor 2 → demoted to player; Admin 1 → demoted to moderator. Admin can look up counts for players / advisors / mods
  • 🛡️ Mod dashboard: site visits, user lookup, live races/collabs (remove players; add, edit, or delete chat as SkyHopMod_#####), level list, stats. Report Advisors do not get this
  • Role powers: Report Advisor, moderator, and Admin each have a list of every power for that role. Only that role can open it. Admin can also open the Report Advisor and moderator lists. The owner can open all three
  • Hosts can set a race or collab to public or private. Public sessions can be watched by anyone from the button above the shop. Moderators, Admin, and the owner can watch private sessions too
  • Owner inbox: promote/demote moderators, gifts, built-in editor, ban dialog
  • Account administration page: disable, re-enable, delete user
  • Owner campaign leaderboard editor on admin page
  • Review mod-approved runs (owner-only nav)
  • Moderator red styling; owner cannot have levels edited by staff
