Where the script goes

  • In the level editor, press </>. The script is saved with the level.
  • Stage time and jump limit are the number fields next to it. -1 means unlimited, and the matching HUD chip stays hidden.
  • Hover an object to see its center, such as Center: (500, 491). Use that point in skyhop.tag.
  • The first scripted stage shows “Loading SPL…” once, then the script starts.

The lines you need

  • The first line must be use skyhop;. Any other use is rejected.
  • name <- expr stores a value. Member assignment such as object.id <- 1 is not SPL.
  • #comment: starts a comment. 1 is true and 0 is false. Close every block with end;.
  • test.while(1): runs one pass per frame, so skyhop.get inside it sees the player change.
  • test.forLoop(start, end, name): counts from start through end, one step at a time, and finishes in the same frame. The third argument is the variable name, not a value.
  • test.ifTrue runs when the condition is 1. test.ifFalse, test.else, test.elseIfTrue, and test.elseIfFalse work too.
  • test.break; leaves the loop. test.continue; skips to the next pass.
  • Comparisons: test.isEqualNumber, test.isGreater, test.isLess. Math: math.add, math.subtract, math.multiply, math.div, math.floor, math.ceil. Floor and ceil take one number and return a whole number. No extra use line.
  • skyhop.wait(n) pauses the script for n seconds, then the next line runs. Put it in test.while. The game keeps moving during the wait.

skyhop.get

  • skyhop.get("stage_time_limit") — the limit for this stage. -1 means no timer.
  • skyhop.get("stage_time_left") — seconds left on this attempt. -1 if unlimited. At 0 the player dies and the stage restarts.
  • skyhop.get("jump_limit") — the jump cap. -1 means unlimited. Assigning a number to the variable that holds it changes the cap for this attempt. Dying puts the stage’s original cap back, then the script runs again.
  • skyhop.get("jumps_remaining") — jumps left this attempt. -1 if unlimited. Ground, double, and wall jumps all count.
  • skyhop.get("is_player_jumping") — 1 for one frame, the frame after a jump starts, then 0. Read it inside the loop. Ground, double, and wall jumps all count.
  • skyhop.get("is_double_jump") — 1 for one frame, the frame after a double jump starts. Ground jumps and wall jumps stay 0. The stage has to allow a double jump.
  • skyhop.get("is_collision") — the script id of a tagged platform or moving platform the player just started touching, or 0. A side hit is chosen over standing on top. The id is reported for one frame, then 0 until the player leaves and touches again. Untagged floors do not count. The object has to be tagged first.
  • skyhop.get("stage_time") — seconds since this attempt started. Dying resets it. This is not the time limit.
  • skyhop.get("total_stage_time") — seconds on the run clock. Dying does not reset it.
  • skyhop.get("player_death_count") — deaths on this run.
  • skyhop.get("player_pos_x") and skyhop.get("player_pos_y") — the center of this player.
  • In a race or collab, each computer runs the script for its own player. If A is jumping and B is not, is_player_jumping is 1 for A and 0 for B. Position, deaths, and the timers work the same way.
  • Any other name returns 0.

Tags and rotate

  • skyhop.tag(x, y, id) gives that id to the object whose center is at (x, y). The center has to be within a pixel. Platforms use the middle of the box. Coins and the spawn use their point.
  • The same id can be given to more than one object.
  • skyhop.rotate(id, degrees) turns every object with that id. Use 90, 180, 270, or a negative amount. Each 90° swaps width and height around the center.
  • skyhop.move(x, y, id) shifts every object with that id. Positive x moves right and positive y moves down. Negative values move the opposite way.
  • skyhop.change_color("#ff8800", id) sets the color of every object with that id.
  • skyhop.hazard(id) makes every object with that id lethal. Touching that platform or moving platform kills the player. skyhop.safe(id) removes that.
  • skyhop.disable_wall_jump(id) makes every wall with that id refuse a wall jump.
  • In the editor, select an object and use Hazardous or No wall jump. Those stay on the object without a script. A script can still change them after the level starts.
  • skyhop.toggle(id) flips every object with that id between there and not there. Not there removes the hitbox. Only objects marked Affected by toggle respond. Make invisible is separate and keeps the hitbox.
  • skyhop.kill() kills this player.
  • skyhop.kill("name") kills the racer with that username or display name.
  • skyhop.kill("closest", x, y) and skyhop.kill("farthest", x, y) kill the player nearest to or farthest from that point, including you.
  • Race and Collab on a level, in My Levels, online levels, or the editor, start that level for everyone. Its script runs for each player.

Toggle from the script

Tag the object first. The names is_affect_by_toggle and default_toggle_state have to be exact. The variable on the left can be anything. Assigning a number to that variable writes the attribute. 1 means affected by toggle, or starts there. 0 means not affected, or starts absent until toggled on.

skyhop.tag(108, 564, 1);
affect_by_toggle <- skyhop.get("is_affect_by_toggle");
affect_by_toggle <- 1;
default <- skyhop.get("default_toggle_state");
default <- 0;

Counters

  • skyhop.counter(name, x, y, v1, v2, ...) shows a counter at that world point. The name is written like a variable, the same way as the name in test.forLoop. One value, two, or as many as you want. Index 0 is the first value. If you leave the values off, it starts at 0.
  • skyhop.counter.update(math.add(name, increment, index, ...)) adds the increment to those indexes. Leave the indexes off and it adds to the first value.
  • skyhop.counter.update(name, value) or skyhop.counter.update(name, value, index) sets that slot to any value. The index defaults to the first value.
  • skyhop.counter.read(name) or skyhop.counter.read(name, index) returns that slot. The index defaults to the first value.

To copy a jump count into the stage’s jump cap, store the cap and then assign the read:

limit <- skyhop.get("jump_limit");
limit <- skyhop.counter.read(jumps, 0);

Random and limits

  • skyhop.random(n) returns a whole number from 0 through n − 1.
  • skyhop.random(low, high) returns a whole number from low through high.
  • File, network, SQL, packages, and system calls are blocked.
  • Dying or restarting the stage runs the script again and puts rotated objects back. The speedrun timer keeps going.

Example

Turn the object at (500, 491) once on the first jump. Later jumps do nothing until the stage restarts. On a new level that point is the middle floating platform, if you have not moved it.

use skyhop;
skyhop.tag(500, 491, 1);
test.while(1):
    test.ifTrue(skyhop.get("is_player_jumping")):
        skyhop.rotate(1, 90);
        test.break;
    end;
end;

Jump, confirm, add

Jump any number of times, then walk into the first wall. Jump again, then walk into the second wall. The first counter shows both jump counts. The second counter becomes their sum. Replace the tag centers with the walls you placed. Hover a wall to see its center. Give the walls different ids from anything else you tag.

use skyhop;
skyhop.tag(180, 500, 1);
skyhop.tag(420, 500, 2);
skyhop.counter(jumps, 80, 70, 0, 0);
skyhop.counter(total, 80, 130, 0);
phase <- 0;
test.while(1):
    test.ifTrue(test.isEqualNumber(phase, 0)):
        test.ifTrue(skyhop.get("is_player_jumping")):
            skyhop.counter.update(math.add(jumps, 1, 0));
        end;
        test.ifTrue(test.isEqualNumber(skyhop.get("is_collision"), 1)):
            phase <- 1;
        end;
    end;
    test.ifTrue(test.isEqualNumber(phase, 1)):
        test.ifTrue(skyhop.get("is_player_jumping")):
            skyhop.counter.update(math.add(jumps, 1, 1));
        end;
        test.ifTrue(test.isEqualNumber(skyhop.get("is_collision"), 2)):
            phase <- 2;
        end;
    end;
    test.ifTrue(test.isEqualNumber(phase, 2)):
        skyhop.counter.update(total, math.add(skyhop.counter.read(jumps, 0), skyhop.counter.read(jumps, 1)));
        phase <- 3;
    end;
end;

Swap is_player_jumping for is_double_jump if only a double jump should count. Put the jump-limit lines inside the loop if the cap should follow the first count.
